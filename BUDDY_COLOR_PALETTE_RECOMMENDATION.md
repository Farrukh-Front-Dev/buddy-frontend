## 🎬 Animation & Interaction Colors

### Hover States
- **Buttons**: Darken by 10% (e.g., `#4F46E5` → `#3F35D5`)
- **Cards**: Add subtle glow (e.g., `0 0 20px rgba(79, 70, 229, 0.2)`)
- **Icons**: Scale + color shift

### Active States
- **Buttons**: Darken by 20%
- **Links**: Underline + color change
- **Tabs**: Indigo-Purple indicator

### Disabled States
- **Opacity**: 50%
- **Grayscale**: Optional
- **Cursor**: Not-allowed
